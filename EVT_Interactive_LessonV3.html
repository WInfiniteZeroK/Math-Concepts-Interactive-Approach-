The Extreme Value Theorem (EVT)

An interactive lesson for first-year calculus: bounded vs unbounded, closed vs not closed, and applying the EVT

Extreme Value Theorem. If f is continuous on a closed, bounded interval [a, b], then f attains an absolute maximum value f(c) and an absolute minimum value f(d) for some numbers c, d ∈ [a, b].

1. Bounded vs Unbounded

Bounded set. A set S ⊆ ℝ is bounded if there is a number M > 0 with |x| ≤ M for every x ∈ S. Otherwise S is unbounded.
Bounded interval. An interval is bounded if both of its endpoints are finite real numbers, e.g. [a, b], (a, b), [a, b), (a, b]. An interval involving −∞ or +∞, such as [0, ∞) or ℝ = (−∞, ∞), is unbounded.
Key idea. "Bounded" means some M works for every element of the set. To show a set is unbounded, show that every M fails: for each M there is an element x with |x| > M. Boundedness of the interval is one of the hypotheses of the EVT.

2. Closed vs Not Closed Intervals

Closed interval. An interval is closed if it contains every (finite) endpoint, e.g. [a, b], [a, ∞). Equivalently: whenever xₙ ∈ I and xₙ → L, the limit L is also in I — you cannot "sneak up" on a point that is missing.
Open / neither. (a, b) excludes both endpoints (open); [a, b) and (a, b] exclude one (neither open nor closed).
Closed ≠ bounded. [0, ∞) is closed but unbounded. The EVT needs both: an interval of the form [a, b] with a, b finite (a compact interval).

3. Applying the EVT

The EVT has three hypotheses. If all three hold, an absolute max and min are guaranteed:

  1. f is continuous on the interval (differentiability is not required);
  2. the interval is closed;
  3. the interval is bounded.
The EVT is an existence theorem: it says the extremes exist, not where they are. Also, the conditions are sufficient, not necessary — if a hypothesis fails, extremes may still exist.

3B. The Closed Interval Method (step by step)

To find the absolute extremes of a continuous f on [a, b]: (i) find critical points in (a, b) — where f′(x) = 0 or f′(x) does not exist; (ii) evaluate f there and at the endpoints a, b; (iii) the largest value is the absolute max, the smallest is the absolute min.

Common mistakes

  • Forgetting to evaluate f at the endpoints.
  • Missing critical points where f′ does not exist (e.g. x^(2/3) at 0, |x| at 0).
  • Including critical points that lie outside the interval.
  • Applying the method on an open or unbounded interval and assuming extremes must exist.
  • Reporting only the x-value: the max/min value is f(c); it occurs at x = c.
